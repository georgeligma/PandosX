hallo 🧡 Welcome to pandosX! A project porting Intel versions of Mac OS X to M series CPUs.
This consists of Injecting kernel modifiers, JIT translators for ARM64 CPUs, Camera drivers, Microphone drivers, USB drivers, Audio drivers, and iGPU driver. No post-installs for drivers.
**note: Our developers are only aiming for M1 and A18 for fist public releases and M1 support will be unstable as the testing will be used in a emulator**
PowerPC builds are **UNSUPPORTED** and will be forever.
Check out the dev betas branch for in-develop versions of pandosX (currently unavailable).
(currently no releases)
